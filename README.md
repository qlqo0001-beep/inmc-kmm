# inmc-kmm

키보드·마우스 입력을 기록해 블록 타임라인에서 다듬고, 정해 둔 **실행 키**로 재생하는 Windows 프로그램입니다. 로지텍 G HUB 편집기와 비슷한 흐름으로 쓰고, 게임(프로세스)별 **프로필**을 두어 같은 실행 키를 게임마다 다르게 쓸 수 있습니다.

- 단일 exe, 설치 없음 (.NET Framework 4 — Windows 10/11 에 기본 포함)
- 프리셋·설정은 exe 옆 `inmc-kmm.json` 에 저장

## 받기 · 빌드
- **받기**: [Releases](../../releases) 에서 `inmc-kmm.exe` 를 내려받아 아무 폴더에 두고 실행합니다.
- **직접 빌드**: 이 저장소를 받고 `build.bat` 를 더블클릭 → 같은 폴더에 `inmc-kmm.exe` 가 생깁니다. Windows 에 기본으로 든 C# 컴파일러(`csc.exe`)를 쓰므로 따로 설치할 것이 없습니다. 소스는 `Kmm.cs` 한 파일입니다.

## 화면 흐름
1. **목록** — 위에 `평소` 와 프로필 탭, 그 아래 고른 탭의 프리셋이 줄로 보입니다(이름 · 유형 · 블록 수 · 실행 키). `+ 새 프리셋` 으로 그 탭에 새로 만들고, 줄을 누르면 편집, 오른쪽 클릭 → 다른 프로필로 옮기기 / 삭제.
2. **이름** — 이름을 치고 Enter.
3. **유형** — 네 가지 중 하나를 고릅니다(편집기에서 언제든 바꿀 수 있음).
4. **편집기** — 블록 타임라인에서 내용을 만들고 `저장`.

## 프리셋 유형 (실행 키를 눌렀을 때)
| 유형 | 동작 |
|---|---|
| 반복 없음 | 한 번 처음부터 끝까지 |
| 누르고 있는 동안 반복 | 실행 키를 누르고 있는 동안 반복, 떼면 멈춤 |
| 설정/해제 | 한 번 누르면 계속 반복, 다시 누르면 멈춤 |
| 시퀀스 | 누를 때마다 다음 한 단위(키 하나 누름~뗌, 클릭 하나, 텍스트 하나…)만 실행. 끝나면 처음부터 |

## 편집기
- **실행 키** 칸을 누르고 키보드 키나 마우스 가운데/X1/X2 버튼을 누르면 등록됩니다(Esc = 취소, × = 지움). 실행 키는 다른 프로그램에 전달되지 않습니다. 같은 프로필 안에서 같은 키를 다른 프리셋이 쓰고 있었다면 그쪽 실행 키는 비워집니다.
- **기록 줄** (실행 키 아래)
  - **기록 단축키** 칸 — 누르고 키를 치면 그 키가 기록 시작/중지 단축키가 됩니다(기본 `F9`). 이 키는 기록에 들어가지 않고 다른 프로그램에도 전달되지 않습니다(편집기 화면에서만 동작). 모든 프리셋에 공통.
  - **☐ 마우스 움직임 기록** — 켜면 마우스 움직임과 클릭 좌표를 기록해 재생 때 그 자리로 가서 누릅니다. 끄면 움직임도 좌표도 기록하지 않아 클릭·휠은 **재생 시점에 커서가 있는 자리**에서 눌립니다.
  - **● 기록 시작 / ■ 기록 중지** 단추 — 단축키와 같은 일을 합니다.
- **기록 중**에는 위에 빨간 띠(`마지막 입력: A`)가 뜨고, **누르는 키·클릭이 타임라인에 바로 블록으로 나타납니다.** 기록 중에는 블록을 고칠 수 없고, 끝내면 그대로 들어갑니다.
- **`+`** 를 누르면 메뉴가 뜹니다.
  - **키 입력 기록** — 바로 기록이 시작됩니다(기록 단추·단축키와 같음). 키보드·마우스 버튼·휠·(켜 두었으면) 마우스 움직임을 기록하고, 띠의 `중지`·`■ 기록 중지`·단축키로 끝냅니다. 클릭은 이 창 안에서 한 것도 다 남고, 마우스로 `중지` 를 눌러 끝냈을 때 그 클릭 하나만 빠집니다.
  - **텍스트 및 이모티콘** — 문장을 그대로 입력하는 블록(한글·이모지 가능).
  - **동작** — 클릭(왼쪽/오른쪽/가운데/X1/X2) 또는 휠 한 번. 재생 시점의 커서 자리에서 실행됩니다.
  - **지연** — 기다리는 시간(ms) 블록.
- **블록**
  - 빨간 네모 = 키보드 키. 마우스 모양 = 마우스 버튼(눌린 버튼 자리만 보라색: 왼쪽/오른쪽/가운데 휠, 옆 버튼은 아래쪽에 `X1`/`X2`). **아래 ▼** 가 누름, **위 ▲** 가 뗌.
  - `72 ms` = 지연. **누르면 그 자리에서 숫자를 고칠 수 있습니다.**
  - 노란 블록 = 텍스트, 파란 블록 = 마우스 이동 경로(점 수·시간), 주황 블록 = 휠.
  - 블록을 누르면 선택(흰 테두리). `Delete` 키 또는 오른쪽 클릭 → 삭제. 새 블록은 선택한 블록 뒤에 들어갑니다(선택이 없으면 끝에).
  - **블록을 끌어서 다른 자리에 놓으면 순서가 바뀝니다**(파란 선이 놓일 자리). 키보드로는 `←`/`→` 로 선택을 옮기고 `Ctrl+←`/`Ctrl+→` 로 한 칸씩 옮깁니다.
- **표준 지연 사용** 을 켜면 모든 지연 블록이 오른쪽 숫자(`50 ms`)로 바뀌어 파란색으로 보이고 그대로 재생됩니다. 이때 지연 블록이나 `50 ms` 를 누르면 표준값을 고칩니다. 끄면 기록된 지연 값이 다시 나타납니다(지워지지 않음).
- **프리셋 색상** — 키 블록 색.
- **지연 랜덤 ± n %** — 숫자를 눌러 폭을 정합니다. 재생 때 모든 지연(표준 지연 포함)이 그 폭 안에서 무작위로 늘거나 줄어듭니다. 예: 100ms 에 ±20% → 80~120ms. 0 = 기록된 그대로.
- **특정 키를 계속 누르고 있기** — 그 키의 `▲` 블록을 지우면(`▼`만 남기면) 됩니다. 다른 키는 평소대로 눌렀다 떼지고, 그 키만 프리셋이 **꺼질 때** 떼집니다.
  - `설정/해제`: 켜져 있는 동안 눌린 채 유지(반복마다 다시 누르지 않음), 실행 키로 끄면 뗌.
  - `누르고 있는 동안 반복`: 실행 키를 놓으면 뗌.
  - `반복 없음`·`시퀀스`: 끝나면 자동으로 뗍니다(키 끼임 방지). 끝난 뒤에도 누른 채 두려면 아래 왼쪽 **`끝나도 누른 채 두기`** 를 켜세요 — 그러면 같은 실행 키를 다시 누르는 것이 "끄기"가 되어 그때 뗍니다.
  - 어느 경우든 편집기로 들어가거나 프로그램을 끄면 자동으로 뗍니다.
- **재설정** = 마지막 저장본으로 되돌림, **저장** = `inmc-kmm.json` 에 쓰고 목록으로. `‹` 로 나가면 저장하지 않은 변경은 버립니다(물어봄).

## 프로필 (게임별로 다른 프리셋)
- 프리셋은 `평소` 또는 프로필 하나에 속합니다. **실행 키에 반응하는 건 지금 작동 중인 프로필의 프리셋뿐**이라, 같은 실행 키를 게임마다 겹쳐 써도 충돌하지 않습니다.
- 탭 줄의 `+ 프로필` → 이름을 치고, 떠 있는 창 중에서 **감지할 프로세스**를 고릅니다(없으면 "감지 안 함", 또는 직접 입력 `javaw`, `LeagueClient.exe` 등). 탭 오른쪽 클릭 → 프로세스 바꾸기 / 이름 바꾸기 / 지우기(프리셋은 평소로).
- **작동 프로필** (오른쪽 위 단추, 트레이 메뉴에도 있음)
  - `자동 (앞 창 감지)` — 0.4초마다 앞에 있는(포커스를 가진) 창의 프로세스를 보고, 어떤 프로필의 것이면 그 프로필, 아니면 `평소`. 게임을 켜 두기만 하고 다른 창을 보고 있으면 평소, 게임 창을 앞으로 가져오면 게임 프로필입니다. 목록의 상태 줄에 지금 앞 창과 작동 프로필이 보이고, 탭에는 `●` 가 붙습니다.
  - `평소` 또는 프로필 이름 — 앞 창과 상관없이 그 프로필로 고정.
- 평소 프리셋은 게임 프로필이 작동 중일 때는 반응하지 않습니다(게임마다 쓸 프리셋을 그 프로필에 넣거나 옮기세요).

## 실행 키가 먹는 때
- **목록 화면**에 있을 때만 실행 키가 동작합니다(편집기 안에서는 안 먹음). 창을 최소화·트레이로 내려 두어도 됩니다.
- 실행 중에는 목록 위에 `▶ 실행 중: 이름` 이 보입니다.
- 재생을 중간에 멈추면 눌린 채 남아 있던 키·버튼은 자동으로 풀어 줍니다.

## 트레이 · 부팅 때 자동 실행
- 목록 아래 `☐ 최소화하면 트레이 아이콘으로` — 켜 두면 최소화할 때 작업 표시줄에서 사라지고 트레이(시계 옆)의 마우스 아이콘으로 들어갑니다. 아이콘 더블클릭 → 열기, 오른쪽 클릭 → 열기 / 작동 프로필 고르기 / 종료. 트레이에 있어도 실행 키는 그대로 먹습니다.
- `☐ 부팅 때 자동 실행 (트레이로 시작)` — 현재 사용자 계정의 시작 프로그램(레지스트리 `HKCU\...\Run`)에 `inmc-kmm.exe --tray` 를 넣고 뺍니다. 로그인하면 창 없이 트레이로 시작합니다. exe 를 다른 곳으로 옮기면 한 번 껐다 켜서 경로를 다시 넣어 주세요.

## 빠른 반복(지연 10ms 이하)에서 렉 줄이기
- 목록 아래 **`입력 최소 간격`** (기본 `1 ms`) — 지연을 얼마로 넣었든 주입 입력 사이를 최소 이만큼 띄웁니다(1 ms = 초당 최대 1000번). 지연 0 블록으로 초당 수천 번 쏘아 앞 창이 버벅이는 것을 막습니다. 렉이 심하면 2~5 ms 로 올리세요. 0 = 제한 없음.
- 지연은 고해상도 대기 타이머(Windows 10 1803+)로 재서 CPU 를 깨우는 횟수가 적고, 시스템 타이머 해상도(timeBeginPeriod)도 건드리지 않습니다.
- 우리가 쏜 입력은 훅에서 표식 한 칸만 읽고 바로 넘깁니다. 그래도 G HUB·Discord 오버레이·보안 프로그램처럼 **저수준 훅을 거는 다른 프로그램**이 많을수록 입력마다 비용이 커지니, 빠른 반복을 쓸 때는 그런 프로그램을 줄이는 것이 가장 효과가 큽니다.
- 같은 효과라면 `지연 0` 여러 개보다 `표준 지연 사용` 을 켜고 5~10 ms 로 두는 쪽이 가볍습니다. 게임 자체가 초당 받을 수 있는 입력 수에도 한계가 있어 그 이상은 의미가 없습니다.

## 알아 둘 것
- 녹화 때 마우스 움직임은 10ms 간격으로 찍습니다. 클릭은 정확한 좌표를 따로 갖습니다.
- 키를 꾹 누르고 있을 때 생기는 자동 반복 입력은 기록하지 않습니다(누름 한 번·뗌 한 번).
- 좌표는 실제 화면 픽셀입니다. 해상도·배율을 바꾸면 녹화한 자리가 어긋납니다.
- 관리자 권한으로 도는 프로그램에는 일반 권한의 입력이 들어가지 않습니다. 그럴 땐 `inmc-kmm.exe` 도 관리자 권한으로 실행하세요.
- 안티치트가 있는 게임에서는 주입 입력이 막히거나 제재 대상이 될 수 있습니다. 각 게임의 규칙을 확인하고 쓰세요.
